**Errors found and fixed**
- **Credentials file overwritten.** A manual migration check ran startup seeding against a scratch database
  but the real storage folder, overwriting `storage/INITIAL_CREDENTIALS.txt`. The seeded accounts in the real
  database were re-synchronised to the passwords in the file, so the file is accurate again. Lesson: always
  set `QG_STORAGE_DIR` together with `QG_DATABASE_URL` for scratch runs (the test fixtures already do).
- **Missing dataset image returned HTTP 500.** Found by running the test suite on a git-only copy (the CI
  simulation). It now returns a clean 404.
- **Third-party telemetry.** Gradio sent analytics requests to `api.gradio.app` and `huggingface.co` on
  startup. Inspection data must stay local, so `GRADIO_ANALYTICS_ENABLED=False` and
  `HF_HUB_DISABLE_TELEMETRY=1` are now set by default.
- **INT8 quantisation collapses MobileNetV3-Small** to 34 % accuracy, a known sensitivity of hard-swish and

  edge recommendation.
- **Calibration option had no effect.** The onnxruntime 1.26 `calibrate_method` option produced byte-identical
  models for MinMax and Entropy, so only MinMax is reported.
- **Shell heredocs dropped files.** One batch of heredocs failed to write any files; they were rewritten with
  the editor tool and verified.
- **Feature-status claims checked against evidence.** The first draft marked video, camera, golden reference
  and drift as "verified manually". The database showed no such runs. Rather than leave unsupported claims,
  automated tests were written for all four and the status updated.

### 2026-11-05: assistant rebuilt, Add a product, linked pages

**Problem reported.** The user reported that the assistant did not work. Probing it with 10 questions showed
that 6 of them (including three of the page's own suggestions) fell through to the same generic summary. Answers
also showed raw `**markdown**`.

**Assistant fix.**
- New offline intent engine with entity extraction and conversation context.
- 13 tools, Markdown answers with in-app links, follow-up suggestions.
- Admits unknown questions instead of padding them with a summary.
- The chat keeps its history for the browser session.

**Add a product.** Users can teach the system a new kind of item from photos of good examples.

- **First protocol (one calibration split, tight novelty threshold).** On the MVTec bottle test set, 28 of 32
  defects came out as *unfamiliar* and 7 of 10 good items went to review.
- **Diagnosis.** Novelty distances were 0.04–0.06 for good items, 0.05–0.15 for defects and 0.36 or more for
  other products, and the max-of-6 calibration underestimated normal variation.
- **Redesign.** Out-of-fold calibration, plus a novelty threshold placed between good items and foreign
  products. On the metal nut, PaDiM had AUROC 0.86 with 30 photos versus 0.98 for PatchCore (validation split),
  so PatchCore decides and PaDiM only escalates to review.
- **Final held-out results.** See RESULTS.md §9.

**Pages.** Clickable KPI tiles, cross-links on every page, a 404 page with links back, and a Playwright crawler
that follows every in-app link.

**Tests.** 85 / 85 pass.
